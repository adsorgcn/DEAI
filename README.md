# DeAI

把 AI 初稿改成带你自己声音的文字。删套话，调节奏，标出该由你亲自写的位置。只标，不替你写。

Make AI drafts sound like you. Removes filler, restores rhythm, marks where your own voice belongs. Marks only, never writes for you.

## 用法 / Use

1. 打开 `prompt.md`，整篇复制到任何 AI。
2. 粘贴你的初稿，前面加 `DeAI:`。
3. 看输出里的 `[💬]` 和 `[📝]` 标记，自己填。

Open `prompt.md`, paste it into any AI, then send your draft prefixed with `DeAI:`. Fill the `[💬]` and `[📝]` markers yourself.
